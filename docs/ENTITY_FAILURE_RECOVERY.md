# 实体工作流错误恢复（2026-10-31）

- 单次请求默认最多3次尝试；连接错误、超时和408/429/500/502/503/504有限重试，退避1秒、2秒。
- HTTP401/403/404视为服务配置问题；额度耗尽、缓存损坏、程序错误仍停止，保留现场。
- finish_reason=length立即结束该次阶段，不重复同样的无效请求。联合抽取改为拆半、50字符以内重叠，最多3层，最小拆分阈值每半约200字符。保留原文偏移，父块半成品不用。
- 联合抽取重试或拆块最终失败：隔离整件商品，记录失败并继续后续商品。其他块的半成品不参与构图。
- 初始实体描述失败：排除该商品全部实体和关系，继续其他商品。
- 消歧失败：双方实体保持独立，该判断记录失败，整个实验标记partial。
- 合并后的描述失败：记录并排除涉及商品，后续语义图只用成功商品。
- 成功响应按请求身份缓存；失败原始响应保留。修改模型、生成上限、拆块策略等须用新输出目录，避免混用。
- 输出failures.json、item_progress.json、status.json及entities.json中的success/failed行；complete只有没有业务阶段错误且消歧候选处理完毕才为true。语义质量人工审核另行进行。
- 部分产物只能显式allow_partial构图；计时脚本标记partial并保留失败，不将它当100件全部成功。
