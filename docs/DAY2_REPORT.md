## 6. 结论与限制

- 本轮属性版没有超过ID-only；不能把“加特征”直接写成效果提升。
- 本轮两种神经模型均未超过相邻转移基线；后续全局图/语义模块仍需同协议验证，不能预设复杂模型必胜。
- 初始化诊断实测标准差：ID=0.04999，类别=0.99899，价格=1.00211。这是当前实现的尺度差异，可能影响融合优化；尚未做同尺度初始化对照，不能将其认定为性能差异的原因。
- 当前是局部图基线，不是完整论文模型；数据版本、时间协议与论文随机9:1不同，不能拿论文表格直接横向排名。
- 原始数据是评论代理会话；价格和描述是快照，不能证明历史时刻已可用。
- 目录固定导致时间后移后的新/低频商品大量OOV；类别/价格并未使本实现自动支持新商品ID冷启动。
- 单种子、验证集结果，不宣称统计显著或线上CTR/GMV收益。
