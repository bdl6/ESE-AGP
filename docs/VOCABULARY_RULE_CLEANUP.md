# 统一商品词表规则清理（2026-11-01）

## 当前可执行规则

- 正式Amazon预处理仅支持paper协议，默认9:1。固定窗口、全局迭代过滤、全部保留商品建立统一词表；历史输入最多20次，目标另算。
- 内存JSON调试路径也改为全局迭代和统一词表、随机会话划分。调试允许独立验证集；正式Amazon仍无验证集。
- 全局行为图和热门统计只使用训练样本，测试商品身份进入词表不表示测试行为进入训练。
- 不按训练未见删除交互或改写测试目标。

## 删除与替换

移除amazon.py中的temporal训练内频次/词表分支，显式传旧protocol会报错。删除configs/amazon_cds_temporal.yaml和configs/amazon_cds_id_only_temporal.yaml。
sessions.py移除时间分位切分、训练专属目录、catalog.get(...,0)映射及未知训练目标删除逻辑，改为统一规则；tiny配置输出改为tiny_global_v2，避免误读旧调试产物。
旧协议专属测试替换为当前协议回归测试，保留模型、实体、图和防御性非法输入/OOV测试。OOV防御不是按训练未见过滤；0仍可作为padding。
同步README、PLAN、CODE_DESIGN和共享结构注释中的错误“训练目录”术语。

## 验证与边界

104项测试通过。回归覆盖测试独有商品仍进入词表且中间点击不删除、训练行为图不读测试、全局级联收敛、独立目标与20条历史、模型梯度及保存加载。
本次没有重建真实数据、训练模型或重跑实体抽取，没有修改历史数据/图/模型。正式当前数据仍为amazon_cds_paper_iterative_v3；旧paper-v1/v2配置和实验结果保留历史含义，不作为新的预处理规范。
